### NOTAS E DIRETRIZES TÉCNICAS

1.  **Formato e Otimização:** Utilizar exclusivamente o formato **WebP**. Todas as imagens devem ter o metadado EXIF higienizado (removendo GPS, modelo de câmera e dados pessoais) antes do upload.
2.  **Dimensões:** Definir atributos `width` e `height` explicitamente no HTML para evitar *Layout Shift*.
3.  **Performance:**
    *   **LCP (Largest Contentful Paint):** Imagens marcadas como Hero devem usar `fetchpriority="high"` e `loading="eager"`.
    *   **Lazy Loading:** Todas as imagens abaixo da dobra devem usar `loading="lazy"`.
4.  **Acessibilidade:** O `alt text` deve ser descritivo e funcional, evitando repetição desnecessária de palavras-chave.
5.  **Restrições Éticas:** É terminantemente proibido o uso de imagens de "antes e depois", corpos idealizados, fotos de celebridades sem contrato de imagem explícito ou selos de certificação sem link para a fonte verificável.

### FLUXO DE TRABALHO

1.  Selecionar imagem correspondente no acervo de 1000+ fotos.
2.  Redimensionar para o tamanho de exibição final (evitar redimensionamento via CSS).
3.  Converter para WebP com compressão lossy (qualidade 75-85%).
4.  Higienizar metadados EXIF.
5.  Salvar em `assets/img/` com o nome exato definido neste inventário.
6.  Atualizar o status para **APROVADO** neste documento.

### OBSERVAÇÃO PRODUTOS

As imagens de produto devem ser salvas localmente. O catálogo oficial (`https://catalogoherbalife.com.br/edusidegum`) serve como referência para validação de dados técnicos e visuais, mas o microsite não deve realizar requisições de imagens para servidores externos.
